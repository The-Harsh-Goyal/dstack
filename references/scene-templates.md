## 1. WeChat Official Account cover / article header image

**Specs**:
- Cover image: 2.35:1 (900×383px or 1200×510px)
- In-article illustration: 16:9 (1200×675px) or 4:3 (1200×900px)

**Key design elements**:
- Visual impact first (users skim quickly through the feed)
- Very little or no text (the Official Account title is overlaid on it)
- Moderate color saturation (the WeChat reading environment leans white)
- Avoid excessive detail (it must stay recognizable as a thumbnail too)

**Recommended styles**: 01 Pentagram / 11 Build / 12 Sagmeister / 18 Kenya Hara / 07 Field.io

**Scene prompt template**:
```

- Moderate color saturation for white reading environment

```

## 2. In-article images / concept illustrations

**Specs**:
- 16:9 (1200×675px), the most versatile
- 1:1 (800×800px), good for emphasis
- 4:3 (1200×900px), good for dense information

**Key design elements**:
- Serves the article's argument, not decoration
- Forms a visual rhythm with the surrounding content
- Expresses one core concept simply
- AI generation first; use HTML screenshots only for precise data tables

**Recommended styles**: choose by the article's tone; commonly 01/04/10/17/18

**Scene prompt template**:
```
[Insert style DNA here]
- Article illustration, concept visualization
- [16:9 / 1:1 / 4:3] aspect ratio
- Single clear concept: [describe the core concept]
- Serve the argument, not decoration
- [Light/Dark] background to match article tone
```

## 3. Infographics / data visualization

**Specs**:
- Vertical long image: 1080×1920px (mobile reading)
- Horizontal: 1920×1080px (embedded in articles)
- Square: 1080×1080px (social media)

**Key design elements**:
- Clear information hierarchy (title → key data → details)
- Accurate data, nothing made up
- Visual guide lines (the reader's path)
- Use icons/charts where they help understanding

**Recommended styles**: 04 Fathom / 10 Müller-Brockmann / 02 Stamen / 17 Takram

**Scene prompt template**:
```
[Insert style DNA here]
- Infographic / data visualization
- [Vertical 1080x1920 / Horizontal 1920x1080 / Square 1080x1080]
- Clear information hierarchy: title → key data → details
- Visual flow guiding reader's eye path
- Icons and charts for comprehension
- Data-accurate, no decorative distortion
```

## 4. PPT / Keynote presentations

**Specs**:
- Standard: 16:9 (1920×1080px)
- Widescreen: 16:10 (1920×1200px)

**Key design elements**:
- One core message per slide (don't pile things up)
- Clear type size hierarchy (title 40pt+ / body 24pt+ / notes 16pt+)
- Lots of whitespace, so it's clearer when projected
- Image-to-text ratio of at least 60:40
- A consistent visual system (colors, fonts, spacing)

**Recommended styles**: 01 Pentagram / 10 Müller-Brockmann / 11 Build / 18 Kenya Hara / 04 Fathom

**Scene prompt template**:
```
[Insert style DNA here]
- Presentation slide design, 16:9
- One core message per slide
- Clear type hierarchy (title 40pt+, body 24pt+)
- Generous whitespace for projection clarity
- Consistent visual system throughout
- [Light/Dark] theme
```

## 8. Xiaohongshu (RED) images

**Specs**:
- Vertical: 3:4 (1080×1440px), best
- Square: 1:1 (1080×1080px)
- The first image decides the click-through rate

**Key design elements**:
- Visual appeal first (competing in the waterfall feed)
- A little text is fine (but no more than 20% of the frame)
- Vivid colors, but not tacky
- A sense of everyday life / texture / atmosphere

**Recommended styles**: 12 Sagmeister / 11 Build / 20 Neo Shen / 09 Experimental Jetset
