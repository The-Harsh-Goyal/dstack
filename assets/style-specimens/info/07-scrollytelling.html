FASTGREP · why it keeps getting slowerCH.03 / 05 Plugins

From v1.0 to v2.2, startup stayed at 12 to 18 ms. Each release added a little; nobody saw a problem.

Until v2.3, the plugin system shipped: at startup it would load every plugin at once.Startup jumped from 18 ms to 41 ms in that release, and has grown every release since.

By v3.3, users with a full plugin set wait 151 ms: twelve times slower than v1.0.
